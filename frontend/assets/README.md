# Static assets

Place reviewed, licensed static image assets here if the interface needs them.
The current interface has no external image, font or icon dependencies: its marks
are CSS shapes and its small controls use inline SVG or text.

The current SOL mark is a placeholder, not an official Sri Aurobindo, The Mother
or AURO University logo. Do not imply institutional endorsement by replacing it
without an approved asset and usage permission.

No generic static-file directory is exposed by the backend. New assets need an
explicit route in the backend's asset mapping and corresponding serving tests.
